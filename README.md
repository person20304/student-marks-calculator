# Student Marks Calculator

A beginner Python project that calculates student marks.

## Features
- Takes the student's name
- Accepts marks for three subjects
- Calculates total and average marks
- Displays pass or fail status

## Requirements
Python 3

## How to Run
Open a terminal in this folder and run:

python student_marks.py

## Concepts Used
- Variables
- Loops
- Lists
- Conditional statements
- Functions
